Welcome to Sterling Bank Technology Academy — Docker Certified Associate Prep, Lab 2.3. This page is served live by the web container, proving the capstone stack deployed correctly from a single Compose blueprint.

web service
nginx:alpine · running
database service
redis:alpine · running
deployed via
docker compose up -d

Web Tier
Delivered on Port 8080

The public-facing edge of the stack. Nginx serves this page to anyone hitting localhost:8080, and starts only after the database service is scheduled — proof that depends_on is doing its job.

nginx:alpine port 8080:80 depends_on: database

Database Tier
Backed by a Named Volume

Redis holds state for the stack, writing to the dashboard_data volume. Because the volume lives independently of the container, data set here survives a container restart — and even a full docker compose down, unless the -v flag is used.

redis:alpine volume: dashboard_data internal only
